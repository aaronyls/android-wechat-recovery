# 设备准备：开发者模式、USB 调试与 ADB 连接

本文档供 Agent **逐条念给用户**，用户按步骤在手机上操作。不同品牌路径差异较大，先确认品牌再选对应章节。

---

## 一、电脑端：安装 ADB

1. 下载 Google 官方 **platform-tools**：
   - Windows: https://dl.google.com/android/repository/platform-tools-latest-windows.zip
   - macOS: `platform-tools-latest-darwin.zip`
   - Linux: `platform-tools-latest-linux.zip`
2. 解压到任意目录，例如 `C:\platform-tools\`
3. 验证：
   ```bash
   C:\platform-tools\adb.exe version
   ```
   输出 `Android Debug Bridge version 1.0.41` 之类即成功。

> 不需要装「XX 手机助手」「XX 套件」等厂商工具，它们常会抢占 ADB 端口造成冲突。
> 若已装过，建议先退出其后台进程。

Windows 上若识别不到设备，可能需要装 USB 驱动：设备管理器里看是否有黄色感叹号的
「Android Device / ADB Interface」，有则右键更新驱动。

## 二、通用步骤：开启开发者选项

绝大多数安卓手机的通用路径：

```
设置 → 关于手机 → 连续点击「版本号」7 次
→ 提示「您现在处于开发者模式」
```

**各品牌「版本号」的具体位置：**

| 品牌 | 路径 | 要点击的项 |
|------|------|-----------|
| **小米 / Redmi**（MIUI / HyperOS） | 设置 → 我的设备 → 全部参数与信息 | **MIUI 版本** / **OS 版本** |
| **华为 / 荣耀**（EMUI / MagicOS） | 设置 → 关于手机 | **版本号** |
| **OPPO / 一加 / realme**（ColorOS） | 设置 → 关于本机 → 版本信息 | **版本号** |
| **vivo / iQOO**（OriginOS） | 设置 → 系统管理 → 关于手机 | **软件版本号** |
| **三星**（One UI） | 设置 → 关于手机 → 软件信息 | **版本号** |
| **原生 Android / Pixel** | 设置 → 关于手机 | **版本号** |

点完会提示「您已处于开发者模式」或要求输入锁屏密码，输入即可。

## 三、开启 USB 调试

### 小米 / Redmi（MIUI / HyperOS）★ 注意事项最多

```
设置 → 更多设置 → 开发者选项
```
需要开启：
- ✅ **USB 调试**
- ✅ **USB 安装**（否则部分 adb 命令受限）
- ✅ **USB 调试（安全设置）** —— 允许通过 USB 修改权限、模拟点击

> **小米特有限制**：开启「USB 调试（安全设置）」通常要求
> ①手机已登录小米账号 ②插入 SIM 卡联网 ③账号登录满一定时长。
> 若开关灰色不可点，先登录小米账号并联网，等待几分钟重试。

### 华为 / 荣耀
```
设置 → 系统和更新 → 开发人员选项 → USB 调试
```
连接后手机会弹「是否允许 USB 调试」，选择「始终允许」。部分机型还需在通知栏把 USB 用途改为「传输文件」。

### OPPO / 一加 / realme
```
设置 → 系统设置 → 开发者选项 → USB 调试
```
另需开启 **「禁止权限监控」**（部分 ColorOS 版本），否则 adb 命令会被拦截。

### vivo / iQOO
```
设置 → 系统管理 → 开发者选项 → USB 调试
```
另需开启 **「USB 模拟点击」** 与 **「未知来源应用安装」**（视机型而定）。

### 三星
```
设置 → 开发者选项 → USB 调试
```

## 四��连接电脑

1. 用**原装或质量可靠的数据线**连接（劣质线常导致传输中断，30GB 级传输尤其敏感）
2. 优先插**主板后置 USB 口**，避免前置面板/USB Hub
3. 手机下拉通知栏 → 点击「正在通过 USB 充电」→ 选择 **「传输文件 / MTP」**
4. 电脑执行：
   ```bash
   adb devices -l
   ```
5. 手机弹出「允许 USB 调试吗？」→ ✅ 勾选「一律允许使用这台计算机进行调试」→ **确定**
6. 再次执行 `adb devices`，状态应为 `device`

```
List of devices attached
66876398    device product:pandora model:25078RKD5C device:pandora
```

## 五、连接排障表

| 现象 | 原因 | 解决 |
|------|------|------|
| `List of devices attached` 后为空 | 驱动未装 / 线缆问题 / 未开 USB 调试 | 换线换口；设备管理器装驱动；确认调试已开 |
| 状态 `unauthorized` | 未在手机上授权 | 手机上确认弹窗；若无弹窗执行 `adb kill-server && adb start-server` 后重插 |
| 状态 `offline` | ADB 服务异常 / 手机休眠 | `adb kill-server` 后重启；开启「充电时不锁屏」 |
| 弹窗一闪而过点不到 | 屏幕未解锁 | 先解锁屏幕再插线 |
| 反复出现授权弹窗 | 未勾选「一律允许」 | 开发者选项 → **撤销 USB 调试授权** → 重新连接并勾选 |
| 传大文件中途断开 | 线缆/USB 口/电脑休眠 | 换原装线+后置口；电源计划设为「高性能」，关闭 USB 选择性暂停 |
| `adb` 命令找不到 | 未加 PATH | 用绝对路径 `C:\platform-tools\adb.exe` 调用 |
| 多设备冲突 | 连了模拟器或多台设备 | `adb devices` 取序列号，用 `adb -s <serial> …` |

## 六、整个流程期间的注意事项

- **保持连接不断开**，中途拔线会导致数十 GB 传输前功尽弃
- 电脑设置为**永不休眠**（Windows：电源和睡眠 → 屏幕/睡眠设为「从不」）
- 手机开启开发者选项里的 **「充电时屏幕常亮」**
- 手机**保持足够电量**或全程插电（备份/恢复过程很耗电）
- 流程期间**不要打开微信**，避免它再次改写数据库状态
